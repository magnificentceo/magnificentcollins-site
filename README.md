# Magnificent Collins website

Live at https://magnificentcollins.com/

- `site/` is the website. Cloudflare publishes only this folder.
- `site/data/releases.js` holds every song, link, lyric and the About text. Edit this file to add a song.
- `qr-codes/` holds the QR codes for https://magnificentcollins.com/.
- `HANDOVER.txt` explains how to add songs, lyrics and comments, and how updates go live.
